# SteamProject

# To run this project

1. Backend Setup
Create a `.env.properties` file with your Steam API key:

mvn clean install (I do this every time)
steam.api.key=YOUR_STEAM_API_KEY
mvn spring-boot:run

The backend will start on `http://localhost:8081`.

2. Frontend Setup

cd frontend
npm run dev

The frontend will start on `http://localhost:5179`.

3. Access the Application

Open your browser and go to `http://localhost:5179` to view the application.
